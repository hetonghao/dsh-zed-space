# 06 视频导入界面原型

问题：视频导入入口如何放进现有设置面板？

原型分支：`codex/video-import-prototype`；首轮三方案提交 `ca4fcf7`，多视频与重命名版本为 `8a9fec0`。
运行：在原型工作树执行 `npm run preview:video`。
页面：`preview/video-import-prototype.html?variant=A|B|C`，底部箭头切换。
仅内存演示，不写真实素材或用户配置。

用户选择 B：第四个「本地视频」入口，与事件视界、吸积涡旋、海面并列。
选择后显示导入区；支持多选本地视频，以两列真实缩略图显示时长、大小和名称。
单选启用通过缩略图上的勾选框完成，最多启用一项；单独移除不影响其余素材。
名称旁编辑按钮进入就地重命名，回车或失焦保存，Esc 取消；不修改原文件。
通用配置沿用现有样式并对视频独立保存。所有文件名按文本显示。

A（独立模式）与 C（展开区）保留在原型分支作为决策来源，不进入正式源码。
实施审查基线：`f99d485`，范围仅为后续 06 功能及必要依赖补齐。

已在真实浏览器使用云海、黑洞和星环三段本地样本验证多选导入、真实缩略图、
启用项互斥、中文名称保存和 Esc 取消。素材和缩略图不提交，也不写真实用户配置。
原型刷新会清空，正式持久化与完整文件预检仍待 06 实现。
