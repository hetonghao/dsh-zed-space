## 2026-10-25 进度核对

三皮肤、独立参数、逐皮肤通用配置、确认恢复和面板动画已实现并本机验收。当前已获用户确认的约定为「通用配置按皮肤独立保存」，替代下文原来的全局公共配置。三条安装路径的真实持久化回归现已补齐并通过，2026-10-25 结票。海面保留波浪、日光与独立自动昼夜控制。

**What to build:** 第二个新皮肤，与 A 同源（同一段参考视频）但**不同创作取向**——
从同一个视觉命题里另取一面，而不是换个配色重做一遍。加上海面，共 3 个可切换皮肤。

同时把面板重构成"公共配置 + 每个皮肤独立配置"两层。面板目前 8 行约 541px、
**没有高度上限也没有滚动**；3 个皮肤 × 各自配置 + 公共配置会顶出小视口。
必须同时解决容量问题（tab / 折叠 / `max-height` + `overflow-y` 皆可）。

### 面板结构

```
[总开关]
├─ 公共配置（对 3 个皮肤都生效）
│    玻璃面板不透明度 / 对话面板独立不透明度 / 随系统时间自动变化昼夜
└─ 皮肤  [海面] [A] [B]        ← 分段控件，切换即时生效
     └─ 当前皮肤的独立配置（每皮肤 ≥3 项）
```

### 每个皮肤的独立配置（内容自定）

海面沿用现有 `波浪大小` / `日光`。两个新皮肤的配置项**自行设计**，方向举例（不必都做）：

- 细丝流速、噪声缩放、色相偏移、辉光强度、星点密度、引力半径
- 主体随鼠标做视差或亮度响应（见 05）
- 点击产生脉冲 / 涟漪 / 星点爆散（见 05）

要求：**每皮肤至少 3 项，且真的只影响该皮肤**。切到别的皮肤时这些控件隐藏或禁用，
不能出现"调了没反应"。

### 持久化

每个皮肤的独立配置**各自持久化**（key 带皮肤 id 前缀），重开页面后恢复。
公共配置单独一组 key。切换皮肤不重置任何值。

⚠️ 这是配置漂移第三次复发的高危点：新增的每个字段都要同时出现在
「默认值 / 归一化 / 面板模板 / 多语言控件清单 / 三处存储适配器」。
01 票已经修了三处适配器的字符串键问题，本票要求为**每个新字段**各验一次三条路径。
