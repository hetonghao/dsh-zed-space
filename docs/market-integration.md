# DSH 视频市场接入

`1.0.1` 起，DSH 插件直接连接 [Zed Space 公网壁纸市场](https://zed-space.ai-cove.com/wallpapers)，在全窗口画廊中浏览、搜索、预览并下载视频，无需启动本地市场服务。此接入属于根目录的 DSH bundle；浏览器扩展和静态加载器仍使用本地视频导入。

## 使用流程

1. 打开皮肤设置的「本地视频」，点击「发现官方精美动态皮肤」。
2. 在画廊搜索、打开详情并选择兼容的视频规格，点击添加。插件下载并校验后，将视频保存到「我的视频」。
3. 点击「应用视频并返回」才切换背景并返回 DSH；也可以先返回本地视频，稍后从列表选择。

顶部「返回本地视频」或 Esc 关闭画廊，并恢复发现入口的焦点。若已点击应用且仍在处理，返回请求会等待这次应用成功或失败后再关闭。重新打开会保留本次插件运行期间的搜索与筛选。原有磁盘文件导入方式继续可用。

- 每个视频最多 **32 MiB、30 秒、长边 1920 / 短边 1080 像素**，须通过现有 MP4/WebM 容器、编码和视频轨检查；具体要求见[本地视频背景](video-background.md)。超限规格可以预览，但不能添加到插件。
- 同一素材标识和 SHA-256 对应的来源已在当前素材库时复用已有条目，不重复入库，也不覆盖用户改过的显示名称。不同内容的版本可以成为新条目。
- 下载或校验阶段取消、关闭会停止后续导入。进入原子保存阶段后，「停止等待」或关闭可能留下已完成的副本；它会留在「我的视频」，不会自动应用。应用始终要求单独点击。
- 页面加载失败或 8 秒内未完成连接时，会提示检查网络，可「返回本地视频」继续导入、使用已保存皮肤，也可「重试」；服务恢复后能够正常进入画廊。嵌入模式不会降级为浏览器另存文件；独立打开市场网站时，原有浏览器下载方式保留。

## 安装与公网地址

在对应 Harness profile 中安装或更新插件，重启该实例后打开「本地视频」：

```sh
dsh plugin --profile web add dsh-zed-space@1.0.1
```

Desktop 使用独立 profile，具体步骤见[安装与排错](install.zh.md)。从 `1.0.0` 更新无需卸载或清理本地视频。真实安装与下载验证范围见[1.0.1 发布记录](publishing/releases/1.0.1.md)；Web 验证不等同于原生 Electron 或 Windows 实机验证。

| 用途 | 固定地址 |
| --- | --- |
| 市场页面 | `https://zed-space.ai-cove.com/wallpapers` |
| 签名目录 | `https://zed-space.ai-cove.com/api/catalog` |
| 公开媒体前缀 | `https://zed-space.ai-cove.com/zed-space-public/` |

市场站由独立 `zed-space` 仓库部署，不是本插件仓库中的 `website/` 静态展示站。插件固定使用生产 Ed25519 验签公钥，其 DER/SPKI SHA-256 为 `a23d8cb5fd06e49f27e35b79d317beddff7012833e553ec9875a090eaa78a1a1`。更换签名密钥时，需要核实新的生产公钥并发布插件更新；不会从目录响应中自动信任新密钥。

## 下载与存储边界

新增网络访问用于展示官方画廊、读取可信目录并取得用户选中的视频。插件服务只对上述固定 HTTPS 上游发起读取请求，不接受任意 URL、不跟随重定向、不上传用户素材，也不加入遥测或远程代码执行。

- `plugin/market-server.js` 用固定 Ed25519 公钥验证原始目录签名；同源 `GET/HEAD /dsh-zed-space/market/catalog` 返回去除媒体 URL 的最小目录，`GET/HEAD /dsh-zed-space/market/media?asset=…&file=…` 只读取目录内的兼容视频。
- 市场消息只提交素材 ID 和 SHA-256，不提交下载 URL、Blob 或磁盘路径。双方核对实际窗口、准确 origin、协议版本及本次 session；查询参数中的 `parentOrigin` 不构成下载授权。
- `shared/market-download.js` 重新读取插件的可信目录，检查声明规格、响应字节数和 SHA-256；随后由现有视频接收端再次核验来源哈希并运行 `inspectVideo`，最后以 IndexedDB 事务入库。
- 已保存的视频可离线播放。文件和缩略图仍保存在 `backspace-videos`，遵守 iframe origin 与宿主 owner 隔离、浏览器存储配额和既有删除规则。市场网站不能直接读写这个库；更换 DSH 域名、端口或浏览器 profile 不会自动迁移素材。

接口只接受 GET/HEAD；非法参数为 400、未知素材为 404、超限规格为 413、签名或上游失败为 503。媒体响应开始后的流错误会断开连接，客户端完整性检查阻止残缺内容入库。安全边界及漏洞反馈见[安全说明](../SECURITY.md)。
