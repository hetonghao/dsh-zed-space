# 本地视频背景

在 Backspace 设置面板中选择第四项「本地视频」，点击「导入视频」。一次可以选择多个文件，
导入后以缩略图列表显示。勾选一个视频用于背景；不会自动轮播，也不会同时播放多个视频。

- 点击名称旁的编辑按钮修改显示名称；回车或移开焦点保存，Esc 取消。原始文件不变。
- 每个视频都可以单独移除。移除正在使用的视频或取消勾选后显示海面，其余素材保留。
- 视频静音循环、等比铺满背景。关闭总开关或隐藏页面时停止播放；减少动态模式只显示静态画面。
- 总开关关闭时仍可在面板内管理视频，但不播放；关闭面板后释放媒体资源。
- 视频的通用配置独立保存。「恢复默认」只恢复当前背景的外观配置，不删除素材。

## 文件要求

每个文件须满足：MP4 或 WebM 容器，H.264、VP9 或 AV1 视频编码，含有效视频轨，
时长大于 0 且不超过 30 秒，体积不超过 32 MiB（界面简写为 32 MB），
最长边不超过 1920 像素、短边不超过 1080 像素。支持竖拍旋转信息。

导入时先检查真实容器和元数据，不依赖文件扩展名或操作系统提供的 MIME。
读取元数据与首帧分别设置 3 秒超时；通过限制检查后只解码首帧生成缩略图，不转码。
批量导入逐个处理，某个文件被拒绝不会删除已导入的素材。错误提示会给出原因及改法。

## 存储与兼容性

视频、缩略图、显示名称和当前选择保存在背景 iframe 所属 origin 的 IndexedDB 中，
数据库名为 `backspace-videos`。浏览器扩展按宿主页面的 origin 分隔素材，不跨宿主共享。
这些内容不进入 `chrome.storage.sync`，不上传到 Google 账号或其它服务。

重启后会恢复当前设备的素材和选择。另一台设备只有同步来的「本地视频」设置、没有文件时，
显示海面和空列表，可以重新导入。更改宿主域名或端口会使用另一个素材库。

整体容量由浏览器存储配额决定，不申请 `unlimitedStorage`。空间不足时先移除不用的视频。
清除站点数据或扩展数据会清空素材库；卸载 DSH 插件本身不保证清理宿主的 IndexedDB。
在面板中逐项移除可清理对应文件和缩略图；原始磁盘文件始终不受影响。

当前验证范围为 Chromium：DSH Host 插件、静态安装、Chrome/Edge 扩展。
视频以 Blob 传入 iframe，由浏览器播放，不经过插件静态服务的 HTTP Range 接口；
不提供进度拖动控件，未承诺 Safari/iOS 支持。旧的 Harness 源码注入 UI 不包含本功能。

## 开发验收

`npm run test:video` 生成临时测试视频并运行真实浏览器验收，需要本机 FFmpeg 和
Playwright Chromium（`npx playwright install chromium`）。测试素材、截图、浏览器配置
和原始日志存放在临时目录或 `.scratch/video-background/`，不进入发布包。
