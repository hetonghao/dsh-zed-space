# 分诊标签

| Matt Pocock 角色 | GitHub 标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由 Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或判断 |
| `wontfix` | `wontfix` | 决定不处理 |

技能提到分诊角色时使用此表对应标签；已分诊的开放实施票保留一个分类标签（`bug` 或 `enhancement`）和一个分诊标签。
