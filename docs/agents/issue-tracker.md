# 本地票据

本项目使用 `.scratch/video-background/issues/` 下的 Markdown 票据；总规格为
`.scratch/video-background/spec.md`，执行与验收记录为 `.scratch/video-background/progress.md`。

状态：`ready-for-agent`、`in-progress`、`implemented-awaiting-validation`、`blocked`、`done`。
结票须记录已完成范围、验收证据及被后续用户决定替代的旧约定。未完成验收不得勾选。
本地素材、截图、安装包和运行日志不提交。只提交规格、票据和文字结论。
