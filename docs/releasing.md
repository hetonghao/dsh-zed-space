# 发布说明

当前版本为 `dsh-zed-space@1.0.0` 候选版，尚未发布。

发布操作统一按 [npm 发布审核](publishing/npm.md)执行；社区清单按 [DSH 市场审核](publishing/dsh-market.md)执行。升级前阅读[迁移说明](publishing/migration.md)。

维护者先完成构建、测试、实际 tarball 安装、许可检查和真实截图核验，再请求发布批准。本轮只准备材料，不运行 `npm publish`、不创建 Release、不提交市场 PR，不启用 Pages 自动发布。

若后续获准发布，registry 与 GitHub Release 必须使用相同字节的 tarball；版本化资产为 `dsh-zed-space-1.0.0.tgz`，稳定资产名为 `dsh-zed-space.tgz`。历史 tags 不等于新品牌已发版。

Chrome Web Store / Edge 扩展商店是单独渠道，本次未提交。扩展发布需另行核对权限、[隐私说明](privacy.md)、商店账号和 ZIP 产物。
