# README 运行截图

这五张图于 2026 年 10 月 27 日重拍，来自真实的 DeepSeek Harness Web 界面。每张图都打开当前壁纸的配置面板。

## 拍摄环境

- macOS；本机 DeepSeek Harness 自带 CLI，版本 `0.2.1-rc.3`。
- 独立 `DSH_HOME`，从官方 `web` 模板建立临时 `readme` profile；服务只监听 `127.0.0.1`。
- 从主分支 `f41caa3dcb064028f9c63a3b89ce921059d44f89` 打包，通过正常的 `dsh plugin --profile readme add <本地 tarball>` 安装 `dsh-zed-space@1.0.0`。
- 独立 Chrome profile，视口统一为 **1440 × 900**。
- 截图为新建会话页，不含私人对话。背景通过插件设置面板选择，视频通过文件导入入口添加，并通过重命名功能设置中文名称。
- 图片直接来自浏览器截图，只做下述压缩，没有替换页面内容、拼接壁纸、调色或改变分辨率。

所有场景的玻璃不透明度均设为滑块最低值 **40%**；开启「对话面板独立调整」，将其不透明度设为 **60%**，比全局值高 20 个百分点。配置面板保持打开，当前壁纸、全局不透明度和会话独立不透明度都能在图中看到。

| --- | --- |

## 视频素材

从本机 Zed Space 素材库获取临时副本，资产 ID 分别为 `sea-of-clouds`、`astronaut-deep-dive`。哈希与上一轮截图使用的素材一致。两段均为 1920 × 1080、H.264、无音轨；时长分别为 15 秒和约 25.17 秒，大小分别约 4.9 MiB 和 4.5 MiB。

视频通过正常导入和播放流程取图，仅用于展示本地视频壁纸效果，不随插件或本仓库分发。配置面板里的「发现官方精美动态皮肤」是已接入的本地验收功能，公网平台尚未开放；本次未通过该入口下载。
