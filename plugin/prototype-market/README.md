# 插件市场交互原型（可丢弃）

在仓库根目录运行：

```sh
npm run prototype:market
```

打开 http://127.0.0.1:4174/?variant=A 。展开动效读取相邻 `zed-space/apps/website/node_modules/gsap/dist/gsap.min.js`，不新增依赖。需要已有市场服务 http://127.0.0.1:4173/wallpapers 正在运行；原型不会启动、重启或修改该服务。

在真实插件的「本地视频」中点击「发现官方精美视频皮肤」。搜索、分类、详情和视频预览来自真实市场；「模拟下载」约 1.5 秒，只演示内存进度。完成后点击「模拟应用」，流式预览同一视频作为 DSH 夹具背景。A/B 应用后自动返回 DSH 查看背景；C 保留分屏预览。可取消、重新模拟、恢复原背景。页面刷新即丢弃状态。

- A 扩展工作台：保留侧栏和会话上下文。
- B 专注画廊：全宽市场、窄返回栏。
- C 边选边看：市场与 DSH 预览分栏，窄屏压为下方小窗。

底部左右按钮或方向键切换，URL 保留方案；输入框、视频控制和滑块不拦截方向键。Esc 退出市场并将焦点交回发现入口。切换方案取消正在模拟的下载，保留市场检索；退出释放市场 iframe，已应用背景保留至恢复。

这是隔离浏览器预览，不是真实 Electron 应用。插件控制器直接复用，设置存储替换为内存 Map，视频运行时替换为空库夹具，空库触发的海面回退使用透明就绪占位页。不会加载真实 IndexedDB 视频库，不会导入、下载或保存视频，不改生产文件。市场页面通过固定本机只读代理嵌入，捕获层拦截下载，iframe 不授予 downloads 权限。预览播放仍会请求视频字节，但不会保存文件。

真实文件大小、格式、完整性和插件兼容校验属于下一步；市场中可预览不代表当前插件能安装。正式接入时重写桥接，不直接提升此原型为生产实现。NODE_ENV=production 会拒绝启动。

源码清单见 source-manifest.json。停止：在启动终端按 Ctrl+C；后台进程 PID 与命令见仓库 .omo/market-prototype-20261026/server.json。
